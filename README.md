# Cyferd's Backend Technical Test

This repository contains the starter code that will be used during the live-coding session for your technical evaluation.

### Setup

This project was set up using:

- [pnpm v10](https://pnpm.io/)
- [Node.js v24](https://nodejs.org/es/download)

Other versions may work, but these are the versions used when preparing the repository.

Before the session, please ensure that:

1. You have installed all project dependencies:

```bash
pnpm i
```

2. You can successfully run the test suite:

```bash
pnpm t
```

If you encounter setup issues, feel free to reach out ahead of time so we can resolve them before the interview.

### What to expect

We will conduct a live-coding exercise, using the code provided in this project.
The exercise will function as a pair-programming session where you will take the lead.
Treat the interviewer as a teammate: feel free to ask questions, get his opinion or request help if you are stuck.

Remember: there is no predefined goal for this exercise, and we don't expect a perfect solution. The exercise is designed so we can observe:

- Your reasoning and thought process
- How you communicate decisions
- How you collaborate while coding
- Your ability to write clean code
